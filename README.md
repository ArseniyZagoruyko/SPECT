# SPECT — моделирование Комптон-камеры для ОФЭКТ

Geant4-проект для моделирования двухслойной Комптон-камеры, применяемой в
системе однофотонной эмиссионной компьютерной томографии (ОФЭКТ / SPECT).
Цель моделирования — изучить отклик детекторов рассеяния и поглощения на
гамма-излучение от точечного/распределённого источника (например, ⁹⁹ᵐTc,
E = 140 кэВ), оценить эффективность регистрации совпадений и накопить
данные для последующей реконструкции изображения по конусам Комптона.

## Физическая идея

В отличие от классической ОФЭКТ с механическим коллиматором, Комптон-камера
использует кинематику комптоновского рассеяния для определения направления
прихода γ-кванта:

1. Гамма-квант комптоновски рассеивается в первом («рассеивающем»)
   детекторе — фиксируются координата вершины и энерговыделение E₁.
2. Рассеянный фотон полностью поглощается во втором («поглощающем»)
   детекторе — фиксируются координата и энерговыделение E₂.
3. По формуле Комптона восстанавливается угол рассеяния θ, а событие
   локализует источник на поверхности конуса с осью, заданной двумя
   взаимодействиями, и углом раствора θ.

Накопление множества таких конусов позволяет реконструировать положение
источника без физического коллиматора, повышая светосилу.

## Геометрия

Мир — куб 5 м × 5 м × 5 м, заполнен сильно разрежённым воздухом
(`DetectorConstruction.cc`).

Две пары детекторов расположены вдоль оси Y (вторая пара по X закомментирована):

| Объект          | Размеры (X×Y×Z), мм | Положение по Y, мм | Материал                |
|-----------------|---------------------|--------------------|-------------------------|
| `radiator1`     | 50 × 4 × 50         | 102                | SrI₂ (сцинтиллятор)     |
| `radiator2`     | 50 × 6 × 50         | 135                | SrI₂ (сцинтиллятор)     |
| `ThinVolume1/2` | 50 × 0.15 × 50      | за радиатором      | Si (имитация SiPM)      |
| `PWB1/2`        | 50 × 1.2 × 50       | за SiPM            | PWB (стеклоткань+эпокс) |
| `Phantom`       | 50 × 192 × 50       | в центре (0,0,0)   | H₂O (водный фантом)     |

Альтернативный материал NaI(Tl) с полными оптическими свойствами также
определён, но в текущей сборке не используется — активный сцинтиллятор
SrI₂(Eu) (ρ = 4.55 г/см³, световыход 115 фот./кэВ).

## Физика

- Базовый список процессов: `QGSP_BIC`.
- Подключены `G4OpticalPhysics` (генерация и транспорт оптических
  фотонов сцинтилляции) и `G4ParallelWorldPhysics` для параллельного
  мира (`MyParallelWorld`).
- Опционально (флаг `lowelectro` в `SPECT.cc`) — атомная физика низких
  энергий: флуоресценция, оже-электроны, оже-каскад, PIXE.
- Глобальный production cut: 0.01 мм; для региона `RadiatorRegion`
  (если активирован) — 0.001 мм.

## Источник частиц (`PrimaryParticles.cc`)

- Частица: γ-квант, моноэнергетический, E = 140 кэВ
  (линия ⁹⁹ᵐTc — рабочая для ОФЭКТ).
- Положение источника: (0, 0, 0) — центр фантома.
- Направление: равномерно по сферическому окну
  Δφ = Δθ = 48° вокруг оси +Y, что соответствует «прицельной» эмиссии
  в телесный угол, перекрываемый детекторной парой.
- В коде сохранены (закомментированы) ветви для:
  - энергетического спектра из 1024-канального аппаратного
    распределения (с калибровкой E = a + b·ch + c·ch²);
  - изотропной эмиссии 4π;
  - выбора одного из двух положений источника.

## Регистрация событий (`SteppingAction.cc`)

На каждом шаге сравнивается имя текущего объёма; для каждого `eventID`
аккумулируется энерговыделение и фиксируется координата первого
γ-взаимодействия в каждом из радиаторов:

- `R1[ev]`, `R2[ev]` — суммарное энерговыделение в первом и втором
  радиаторах (без оптических фотонов).
- `Rx1,Ry1,Rz1` / `Rx2,Ry2,Rz2` — координаты γ-вершин.
- `T1/T2/Tx/Ty/Tz` — то же для второй пары (по оси X), сейчас не
  активной геометрически.

В конце события (по смене `eventID`) совпадения с ненулевым
энерговыделением в обоих радиаторах записываются в:

| Файл                              | Содержимое                                              |
|-----------------------------------|---------------------------------------------------------|
| `deposits_FirstDet.txt`           | `eventID  E1  E2` (кэВ)                                  |
| `GammaCoordinates_FirstDet.txt`   | `eventID  x1 y1 z1  x2 y2 z2` (мм)                       |
| `deposits_SecondDet.txt`          | то же для второй пары                                    |
| `GammaCoordinates_SecondDet.txt`  | то же для второй пары                                    |

Бинарный поток координат оптических фотонов и регистрация
back-scattering-событий присутствуют в исходниках в виде
закомментированных блоков — могут быть включены по необходимости.

## Сборка

Требования: Geant4 (со включёнными UI/Vis), CMake ≥ 3.12, C++ компилятор
с поддержкой используемого Geant4. Перед сборкой должно быть установлено
окружение Geant4 (`source geant4.sh`).

```bash
mkdir -p build && cd build
cmake ..
make -j
```

В каталог сборки автоматически копируются `init_vis.mac` и `vis.mac`.

## Запуск

```bash
cd build
./SPECT
```

Количество разыгрываемых первичных частиц задаётся в `SPECT.cc`
(`int number = 100000`). По умолчанию визуализация отключена
(`bool visual = false`); для включения VRML-вывода поставьте `visual = true`
или используйте интерактивные макросы `init_vis.mac` / `vis.mac`.

После завершения работы в каталоге запуска появятся четыре текстовых
файла с данными совпадений (см. таблицу выше).

## Постобработка

Данные `deposits_*.txt` и `GammaCoordinates_*.txt` пригодны для
дальнейшей реконструкции в Python/ROOT: построения спектра суммарной
энергии E₁+E₂, отбора фотопикового окна и реконструкции конусов
Комптона (изображение `reconstruction_with_profile.png` в корне —
пример визуализации результата реконструкции с профилем).

## Замечания

- В коде намеренно сохранены большие массивы фиксированной длины
  `1e8` и закомментированные блоки альтернативных режимов
  (изотропный источник, аппаратный спектр, бинарный вывод
  оптических фотонов, регистрация обратного рассеяния) — это
  «строительные блоки» для расширения модели, а не мёртвый код.
- Параллельный мир `MyParallelWorld` зарегистрирован, но
  геометрически пуст — заготовка для наложения логических объёмов
  (например, областей подсчёта дозы) без изменения основной геометрии.
